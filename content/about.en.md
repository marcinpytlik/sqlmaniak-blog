## Hi, I'm Marcin 👋

I'm a DBA and engineer working with **SQL Server 2016–2022**, including Query Store, Extended Events, Always On, performance tuning, and security.

I'm especially interested in monitoring with Grafana, InfluxDB, and Telegraf, automating administrative tasks with PowerShell, and sharing practical technical knowledge.

- 🛡️ Security checklists and operational best practices
- 🔧 Dashboards and downloadable scripts

### Technical environment

- 🔧 Production and lab work: Windows Server 2022, SQL Server 2022 Developer, Docker Desktop

- 🧰 Tools: VS Code, PowerShell, GitHub Actions
