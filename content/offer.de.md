## Praxisorientierte Schulungen

Die folgenden Themen gehören zum bestehenden polnischen Schulungskatalog. Umfang, Unterrichtssprache, Termine und Konditionen werden für jede Anfrage gesondert vereinbart.

- **SQL Server & T-SQL:** T-SQL-Grundlagen (5 Tage), fortgeschrittenes T-SQL (5 Tage), SQL Server-Administration (5 Tage), SQL Server High Availability & Disaster Recovery (5 Tage)
- **Anwendungsentwicklung:** EF Core aus Sicht eines DBA (3 Tage), C# und .NET 10, ASP.NET Core Web API in .NET 10, Azure Cloud Developer
- **Administration & Observability:** IIS auf Windows Server 2022 Core, PowerShell-Automatisierung, Zabbix und Grafana

Die Schulungen kombinieren Demonstrationen, praktische Labs, Fehlersuche und realitätsnahe Szenarien. Detaillierte Agenden und Voraussetzungen richten sich nach dem gewählten Kurs.
