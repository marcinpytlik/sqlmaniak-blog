PowerShell nie jest tylko powłoką do uruchamiania pojedynczych poleceń. Jest językiem automatyzacji administracji, który pozwala budować powtarzalne, testowalne i bezpieczne narzędzia operacyjne.

Właśnie temu służy moje szkolenie **„PowerShell — automatyzacja administracji i infrastruktury”** — pięć dni praktycznej pracy od pipeline i obiektów, przez skrypty, funkcje i remoting, aż do REST API, modułów, testów Pester i końcowego Automation Capstone.

## Dla kogo jest to szkolenie?

Szkolenie jest przeznaczone dla:
- administratorów Windows Server,
- administratorów SQL Server,
- inżynierów infrastruktury i DevOps,
- osób automatyzujących zadania operacyjne,
- zespołów utrzymujących środowiska Windows i usługi Microsoft.

Nie jest wymagane doświadczenie programistyczne, ale przydatna jest podstawowa znajomość administracji Windows.

## Automation Capstone

Uczestnik buduje narzędzie **Infrastructure Health Collector**, które:
- odpytuje wiele hostów,
- sprawdza usługi i procesy,
- analizuje miejsce na dyskach,
- pobiera zdarzenia z Event Log,
- sprawdza wybrane endpointy,
- wykonuje podstawowe testy SQL Server,
- zapisuje wynik do pliku lub JSON,
- loguje błędy,
- działa zdalnie i powtarzalnie.

## Rezultat szkolenia

Po szkoleniu uczestnik potrafi pisać skrypty i funkcje PowerShell, automatyzować administrację wielu serwerów, integrować się z REST API i SQL Server oraz budować narzędzia możliwe do testowania i ponownego użycia.
