Działające API to dopiero początek.

Produkcyjne Web API powinno mieć czytelny kontrakt, walidację, poprawną obsługę błędów, bezpieczeństwo, monitoring, testy oraz przewidywalne zachowanie pod obciążeniem.

Właśnie temu służy moje szkolenie **„ASP.NET Core Web API w .NET 10”** — pięć dni pracy od pierwszego endpointu aż do kompletnego API z SQL Server, authentication, observability, resilience i testami integracyjnymi.

## Dla kogo jest to szkolenie?

Szkolenie jest przeznaczone dla:
- programistów C# i .NET,
- developerów backend,
- zespołów budujących REST API,
- developerów pracujących z EF Core i SQL Server,
- osób przygotowujących aplikacje do wdrożenia w środowiskach kontenerowych lub chmurowych.

Uczestnik powinien znać podstawy C#, klas, interfejsów, kolekcji oraz async/await.

Końcowe rozwiązanie obejmuje REST API, SQL Server i EF Core, DTO i validation, authentication i authorization, ProblemDetails, structured logging, rate limiting, health checks, resilience, testy jednostkowe i integracyjne oraz uruchomienie w kontenerze.
