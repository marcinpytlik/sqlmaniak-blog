SQL Server is more than tables, indexes, and queries. It is a vast engine constantly bringing order to the chaos of data — writing, recovering, compressing, and managing every byte.

That is why a new series is launching: **Inside SQL Server 2022** 🎬. The project aims to reveal **the inner workings of the engine** — as the system sees them, rather than the administrator.

---

### 🔍 What is the series about?

In every episode, we look deeper — from data-page structures to the transaction log and recovery mechanisms. Instead of slides, expect real code, `DBCC PAGE`, `fn_dblog`, and a hands-on SQL Server 2022 laboratory.

You will see how the engine allocates extents, what happens to TempDB under pressure, and why ARIES is at the heart of transaction processing.

---

### 🎥 First episodes

1️⃣ **Welcome Inside SQL Server** — an introduction to the series.
2️⃣ **Before You Begin…** — data pages, extents, MDF/NDF/LDF files.
3️⃣ **HOBT — How SQL Server Organizes Data**.
4️⃣ **WAL/ARIES — The Transaction Engine**.

And later: TempDB, compression, the buffer pool, ADR, snapshots, transaction logging, and the internals of backup.

---

### 🧠 Who is it for?

Anyone who wants not only to write queries but also to understand *how* SQL Server really thinks.

The series is designed for administrators, developers, and students who want to explore database internals from the Storage Engine perspective.
