SQL Server besteht nicht nur aus Tabellen, Indizes und Abfragen. Dahinter steckt eine riesige Engine, die ständig Ordnung in das Chaos der Daten bringt — sie schreibt, stellt wieder her, komprimiert und verwaltet jedes Byte.

Deshalb startet eine neue Serie: **Inside SQL Server 2022** 🎬. Das Projekt zeigt **das Innenleben der Engine** — aus der Perspektive des Systems und nicht nur des Administrators.

---

### 🔍 Worum geht es in der Serie?

In jeder Folge schauen wir tiefer hinein — von der Struktur der Datenseiten bis zum Transaktionsprotokoll und den Recovery-Mechanismen. Statt Folien gibt es echten Code, `DBCC PAGE`, `fn_dblog` und ein praxisnahes SQL-Server-2022-Labor.

Du wirst sehen, wie die Engine Extents zuordnet, was in TempDB unter Last passiert und warum ARIES im Mittelpunkt der Transaktionsverarbeitung steht.

---

### 🎥 Die ersten Folgen

1️⃣ **Willkommen im Inneren von SQL Server** — eine Einführung in die Serie.
2️⃣ **Bevor du beginnst …** — Datenseiten, Extents und MDF-/NDF-/LDF-Dateien.
3️⃣ **HOBT — Wie SQL Server Daten organisiert**.
4️⃣ **WAL/ARIES — Die Transaktions-Engine**.

Danach folgen TempDB, Komprimierung, Buffer Pool, ADR, Snapshots, Transaktionslog und die Interna von Backups.

---

### 🧠 Für wen ist die Serie gedacht?

Für alle, die nicht nur Abfragen schreiben, sondern verstehen möchten, *wie* SQL Server wirklich arbeitet.

Die Serie richtet sich an Administratoren, Entwickler und Studierende, die die internen Datenbankmechanismen aus Sicht der Storage Engine kennenlernen möchten.
