## Hands-on training

The following subjects are covered in the existing Polish training catalogue. Scope, delivery language, schedule, and commercial terms should be agreed for each engagement.

- **SQL Server & T-SQL:** Fundamentals of T-SQL (5 days), Advanced T-SQL (5 days), SQL Server administration (5 days), SQL Server High Availability & Disaster Recovery (5 days)
- **Application development:** EF Core Through the Eyes of a DBA (3 days), C# and .NET 10, ASP.NET Core Web API in .NET 10, Azure Cloud Developer
- **Administration & observability:** IIS on Windows Server 2022 Core, PowerShell automation, Zabbix, and Grafana

Training uses demonstrations, practical laboratories, troubleshooting exercises, and real-world scenarios. Exact agendas and prerequisites depend on the selected course.
